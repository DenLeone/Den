⚡ REEL HOOK BATCH

Genera reel con testo fisheye, in automatico

Incolla le tue frasi hook, carica sfondi (foto o video), il tool produce un video pronto per ognuna — con l'effetto testo "bulge/fisheye" bruciato dentro. Tutto gira nel tuo browser, nessun file lascia il computer.

1 Le tue frasi hook

Una frase per riga. Verrà generato un video per ogni riga (gli sfondi si alternano automaticamente se ne hai meno delle frasi).

2 Sfondi (foto o video)

Carica una o più foto/video da usare come sfondo. Le foto diventano automaticamente un breve clip con zoom lento (effetto Ken Burns).

📁 Trascina qui i file, o tocca per scegliere
JPG, PNG, MP4, WEBM, MOV

3 Stile e opzioni

In corso...
Elaborazione 100% locale nel browser — niente upload su server esterni. Formato esportato: WebM (importalo in CapCut/InShot per l'export finale in MP4 se ti serve per l'upload nativo).
